**Mistake:**

### 4. Forgot to add the new book to the catalog

**Mistake:**

**Fix:**

### 5. Repeated total-book count

**Mistake:**  
I initially placed `print(len(books))` inside the for loop, which printed the total number of books repeatedly.

**Fix:**  
I moved the total count outside the loop so it is displayed only once.

### 6. Displaying categories from book records instead of the set

**Mistake:**  
I initially printed each book's category directly. This could display duplicate categories.

**Fix:**  
I displayed `library_categories`, which stores unique category values.

### 7. Incorrect or fixed success messages

**Mistake:**

**Mistake:**  
I initially used `library_categories - student_wishlist` for the purchase order.

### 9. Missing invalid-choice handling

**Mistake:**

## FINAL TESTING NOTES

- The book catalog uses a list of tuples.
- Library categories are created using set comprehension.
- New books are added using `append()`.
- New categories are added using `add()`.
- Intersection (`&`), difference (`-`), and union (`|`) are used for category gap analysis.
- The menu runs inside a `while` loop and exits using `break`.

## REMAINING OPTIONAL IMPROVEMENTS

1. If a user enters a letter instead of a number for the menu choice, `int(input())` can raise a `ValueError`. This can be handled using `try-except`.
2. `.title()` changes "AI" into "Ai". Therefore, a consistent naming convention should be used for both library and wishlist categories.
